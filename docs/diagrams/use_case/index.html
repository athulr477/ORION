Role Breakdown for Report Chapter 3

The Use Case model reflects the strict Role-Based Access Control (RBAC) boundaries implemented across Orion's backend API and React dashboard:

🛡️ QA Lead / System Administrator

  • Sync Project Data: Triggers Jira issue webhook ingestion and pull request AST extractions.
  • Configure Sensitivity Thresholds: Controls τsem (semantic similarity) and τstruct (AST structural overlap) range sliders.
  • Override Trace Risk Verdict: Performs authoritative manual acceptance or rejection on ambiguous links with justification.
  • Simulate Reclassification: Executes matrix simulations and inspects similarity distribution heatmaps.
  • View RTM Dashboard: Monitors real-time coverage statistics and matrix verification progress.
  • Authenticate Session: Switches roles via the RBAC authentication gate.

💻 Software Developer

  • View RTM Dashboard: Inspects requirements mapped to test cases and reviews coverage status.
  • Inspect AST Evidence: Examines extracted test function signatures, docstrings, and assertion operands.
  • Review XAI Explanations: Reads natural language gap rationales verbalized by the local Ollama Llama 3.1:8b engine.
  • Trigger PR Verification Gating: Pushes commits and receives automated GitHub Check Run status feedback.
  • Authenticate Session: Logs in under developer boundaries (policy sliders & override buttons are locked).
